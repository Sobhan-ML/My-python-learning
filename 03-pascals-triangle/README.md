# Pascal's Triangle Generator

A clean Python implementation that generates and prints Pascal's Triangle up to $n$ rows using a recursive approach.

## What is Pascal's Triangle?
Pascal's Triangle is a triangular array of numbers. Each number is the sum of the two numbers directly above it.
