# Number Guessing Game

A simple and fun Python game where the computer selects a random number between 1 and 99, and the player tries to guess it.

## How It Works
- The program generates a random target number.
- It prompts the user to input a guess.
- If the guess is too high or too low, the program gives a hint ("Mine is smaller" or "Mine is bigger").
- The game continues until the user guesses the correct number.

## How to Run
Make sure you have Python installed, then run the following command in your terminal:
`bash
python main.py
